In the dot product operation, we computed the dot product between two different vectors x and y. Now, what happens if we compute the dot product of a vector with itself? This results in what is called the norm of a vector.
Suppose x is a vector in three-dimensional space. The norm of a vector is given by the dot product of x with itself, followed by taking the square root of the result. The norm of a vector is represented using double vertical bars, ||x||, which is a standard mathematical notation.
Mathematically, the norm is computed as:
||x|| = sqrt(x^T x)
Since the dot product between x and itself involves squaring each element and summing them, the result is:
||x|| = sqrt(x1² + x2² + ... + xd²)
The norm of a vector represents its magnitude or length. The specific norm we computed here is known as the L2 norm or Euclidean norm.
For example, consider x = (3,4) in a two-dimensional space. The norm is computed as:
||x|| = sqrt(3² + 4²) = sqrt(9 + 16) = sqrt(25) = 5
Geometrically, the norm represents the length of the line joining the origin to the vector x.
There are different types of norms. The L2 norm, which we computed, is the most commonly used. It is represented as ||x||₂, indicating that it is the L2 norm. A more generic form of norm is the Lp norm, where p can be any value from 0, 1, 2, up to infinity.
The Lp norm is defined as:
||x||ₚ = (Σ |xi|^p)^(1/p)
For p = 2, this becomes the L2 norm (Euclidean norm).
For p = 1, it is the L1 norm, which is simply the sum of the absolute values of the elements.
For p = ∞, it is the L-infinity norm, which takes the maximum absolute value among the vector elements.
For p = 0, it is the L0 norm, which counts the number of nonzero elements in the vector.
For example, if x = (7, -6, 3), the L∞ norm is 7, as it is the maximum absolute value. If x = (-2, -10, 6), the L∞ norm is 10.
The L0 norm counts the number of nonzero elements. If x = (1, 0, 3, 0, 6), then the L0 norm is 3, as there are three nonzero elements.

These different norms provide different types of information about a vector. The L2 norm measures length, the L1 norm sums the magnitudes, the L∞ norm captures the maximum element, and the L0 norm measures sparsity.
Norms play a crucial role in machine learning when dealing with data. If a feature vector contains mostly zero values, it is considered sparse. The L0 norm helps measure how sparse a vector is, which is useful in feature selection for machine learning models.
Another important concept is the unit vector, which is a vector with a norm (length) of 1. A vector x can be converted into a unit vector by dividing it by its Euclidean norm:
x̂ = x / ||x||
For example, if x = (3,4), then ||x|| = 5, so the unit vector is:
x̂ = (3/5, 4/5)
The unit vector points in the same direction as x but has a magnitude of 1.
Another important concept in machine learning is similarity and dissimilarity measures. The Euclidean distance between two vectors measures how far apart they are.
The Euclidean distance between two vectors x and y is given by the L2 norm of their difference:
||x - y||₂ = sqrt(Σ (xi - yi)²)
If the distance is high, the vectors are dissimilar. If the distance is small, the vectors are similar. This makes Euclidean distance a measure of dissimilarity.
Alternatively, we can measure similarity using the cosine similarity, which is given by:
cos(θ) = (x^T y) / (||x|| ||y||)
The cosine similarity measures the angle between two vectors. If θ = 0, the vectors are identical, and cos(0) = 1. If θ = 90°, the vectors are orthogonal, meaning cos(90) = 0, indicating no similarity.
In summary, we explored dot products, vector norms, unit vectors, Euclidean distance, and cosine similarity. These concepts form the foundation for many machine learning algorithms and will be used extensively in later discussions.
